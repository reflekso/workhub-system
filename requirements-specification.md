# Техническое задание

## Цель

Разработать систему откликов в сервисе 'WorkHub'.

## Описание

Система откликов должна включать в себя следующие возможности:
1. Исполнитель должен иметь возможность оставлять отклик на заказ.
2. Исполнитель должен иметь возможность просматривать список своих откликов.
3. Исполнитель должен иметь возможность отменять отклик на заказ.
4. Заказчик должен иметь возможность просматривать список Исполнителей, оставивших отклик на заказ.
5. Заказчик должен иметь возможность выбирать Исполнителя для своего заказа из списка откликнувшихся.
