# Задание на Frontend : Взаимодействие API с интерфейсом

## Цель

Внедрить вызов API-методов в элементы интерефейса на клиенте для системы откликов сервиса "WorkHub".

## Описание

Данное задание описывает когда нужно вызывать API-методы. Все элементы интерфейса с которыми надо взаимодействовать для вызова методов находятся [здесь](https://www.figma.com/design/ryTmDLnQzEQwc8gFVYgA8E/workhub-system?node-id=0-1&t=RxWncHeuFL1xjDva-1).

## Функциональные требования

### Общая обработка ошибок

1. Клиент должен отображать ошибки от сервера в отдельном окне.
2. Текст ошибки Клиент должен брать из поля `message` в теле ответа.

### FE-1 Оставить отклик   

1. Клиент должен отображать кнопку "Откликнуться" на странице заказа для пользователей с ролью `freelancer`, если заказ находится в статусе `published`.
2. Клиент должен отображать окно отклика с сопроводительным текстом при нажатии на кнопку "Оставить отклик"
3. Клиент должен отправлять `POST /api/v1/jobs/{job_id}/proposals` запрос с передачей поля `proposal_message` и токена доступа при нажатии на кнопку "Отправить отклик" в окне отклика с сопроводительным текстом.
4. Клиент не должен отправлять запрос при нажатии на кнопку "Отправить отклик", если превышена допустимая длина сопроводительного текста (не более 500 символов).

### FE-2 Просмотреть список откликнувшихся

1. Клиент должен отправлять `GET /api/v1/jobs/{job_id}/proposals` запрос при переходе пользователя с ролью `client` на страницу своего заказа.
2. Клиент должен отрисовывать список откликнувшихся с учетом параметров пагинации.

### FE-3 Выбрать исполнителя

1. Клиент должен отображать кнопку "Выбрать исполнителя" напротив отклика в Списке откликнувшихся для пользователя с ролью `client` на странице его заказа, если:
    1. Статус этого отклика не `cancelled`
    2. Статус заказа `published`
2. Клиент должен отображать окно подтверждения выбора исполнителя при нажатии на кнопку "Выбрать исполнителя".
3. Клиент должен отправлять `PATCH /api/v1/jobs/{job_id}/proposals/{proposal_id}` запрос с передачей поля `proposal_status` со значением `accepted` при нажатии на кнопку "Выбрать исполнителя" в окне подтверждения выбора исполнителя.

### FE-4 Просмотреть список моих откликов 

1. Клиент должен отправлять `GET /api/v1/users/me/proposals` запрос при переходе пользователя с ролью `freelancer` на страницу личного кабинета.
2. Клиент должен отрисовывать отклики на вкладке "Список откликов" с учетом параметров пагинации.

### FE-5 Отменить отклик

1. Клиент должен отображать кнопку "Отменить отклик" напротив отклика в Списке моих откликов для пользователя с ролью `freelancer` на странице личного кабинета на вкладке "Список откликов", если статус отклика `pending`.
2. Клиент должен отображать окно подтверждения отмены отклика при нажматии на кнопку "Отменить отклик".
3. Клиент должен отправлять `PATCH /api/v1/users/me/proposals/{proposal_id}` запрос с передачей поля `proposal_status` со значением `cancelled` при нажатии на кнопку "Да, отменить отклик" в окне подтверждения отмены отклика. 

## Нефункциональные требования

1. Веб-приложение должно корректно работать в актуальных версиях современных браузеров: Google Chrome, Mozilla Firefox, Apple Safari и Microsoft Edge.
2. Интерфейс должен корректно отображаться и сохранять полную работоспособность на устройствах с шириной экрана от 360 px до 1920 px без появления горизонтальной прокрутки и наложения элементов.
